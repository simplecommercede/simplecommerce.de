AKTUELLE SHOPVERWALTUNG · STAND 04.11.2026

Menüweg: Verwaltung → Artikelattribute

Attributsets fassen zusammengehörige Auswahlfelder zusammen. Sie helfen, wiederkehrende Produkteigenschaften strukturiert anzulegen.

Schritt für Schritt

  1. Set auswählen oder anlegen

    Wählen Sie ein vorhandenes Set oder legen Sie ein neues Set an. Geben Sie einen eindeutigen Setnamen ein, zum Beispiel „Geschenkverpackung“.

  2. Preisart festlegen

    Prüfen Sie „Preis Darstellung“ und wählen Sie netto oder brutto passend zu den vorgesehenen Attributpreisen.

  3. Auswahlfelder aufbauen

    Ordnen Sie Obergruppe, Attributengruppe und Attribut in der angezeigten Reihenfolge zu. Ändert sich eine übergeordnete Auswahl, prüfen Sie die darunterliegenden Zuordnungen erneut.

  4. Am Produkt kontrollieren

    Speichern Sie das Set und prüfen Sie die Verwendung in der Produktverwaltung. Attribute sind von lagergeführten Produktvarianten zu unterscheiden.

Desktop und Smartphone

Hinweise für die mobile Nutzung

Bei abhängigen Auswahlen wird ein Teil der Felder erst nach der vorherigen Auswahl sinnvoll bedienbar. Gehen Sie auch mobil von oben nach unten vor.

Die Abbildungen stammen aus einem separaten Demoshop. Produkte, Personen, Adressen und Bestellungen sind fiktive Beispiele. Menüpunkte können je nach Benutzerfreigabe und Shopkonfiguration abweichen.
