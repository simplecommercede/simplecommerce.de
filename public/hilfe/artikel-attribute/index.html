Attributset anlegen, wählen und wiederverwenden

Attribute bieten konfigurierbare Optionen wie Geschenkverpackung, Material oder Auflage. Öffnen Sie „Artikel Attribute“, wählen Sie ein vorhandenes Set oder legen Sie über das Plus ein neues Set an. Geben Sie einen eindeutigen Namen ein und prüfen Sie die Preisdarstellung netto/brutto. Ordnen Sie das Set anschließend beim Produkt unter „Zubehör“ zu.

Ein Set kann mehreren Artikeln zugeordnet sein. Änderungen und Löschungen wirken daher über den gerade geöffneten Artikel hinaus. Eine Kopie eignet sich als Ausgangspunkt für eine abweichende Konfiguration; geben Sie ihr sofort einen unterscheidbaren Namen. Prüfen Sie vor dem Löschen, welche Produkte das Set verwenden.

Obergruppen, Attributgruppen und Attribute

  1. Legen Sie bei Bedarf über das jeweilige Plus eine Obergruppe an, beispielsweise „Geschenkoptionen“.
  2. Wählen Sie eine Attributgruppe zur Unterteilung oder „keine“, wenn keine zusätzliche Gruppierung benötigt wird.
  3. Legen Sie das eigentliche Attribut an, etwa „Verpackung“.
  4. Wählen Sie die Kombination aus den drei Auswahlfeldern und übernehmen Sie sie mit „hinzufügen“ in die Attributliste.

Die Liste enthält danach eine Zeile je zugeordneter Kombination. Über „sortieren“ legen Sie die Reihenfolge fest. Diese ist bei Berechnungen relevant: Eine spätere Zeile kann auf vorherige Ergebnisse aufbauen. Verwechseln Sie das Entfernen einer Zuordnung nicht mit dem Löschen des zugrunde liegenden Attributs.

Die Berechnungs- und Anzeigefelder

Pflichtfeld
Unterbindet die leere Auswahl. Ein definierter Standardwert bildet dann die Ausgangsauswahl.
Zwischensumme
Steuert die Ausgabe des Zwischenpreises für dieses Attribut.
Runden
Rundet den Zwischenwert auf zwei Nachkommastellen. Prüfen Sie bei Ihrer Berechnung insbesondere Werte mit Nachkommastellen.
Multiplikator
Wählt eine vorherige Berechnungsgrundlage. Die Reihenfolge wird von oben nach unten ausgewertet; eine darunter stehende Zeile kann noch nicht als vorheriges Ergebnis dienen.
Rechnung
Unterscheidet bei einer Multiplikation die Multiplikatormenge eines Wertes von der Zwischensumme des ausgewählten Attributs.
Addieren
Nimmt das Ergebnis in die Gesamtsumme auf. Für eine reine Hilfsberechnung kann die Addition ausgeschaltet bleiben.
Anzeige
Steuert die Sichtbarkeit im Shop. Ein ausgeblendetes Attribut kann mit seinem Standardwert weiterhin an der Berechnung teilnehmen.

Die Einstellung der Preisdarstellung ändert nicht die Bedeutung eines ausdrücklich als „Preis(netto)“ beschrifteten Eingabefeldes. Testen Sie eine einfache Kombination von Hand, bevor Sie mehrere voneinander abhängige Berechnungen einsetzen.

Werte, Preise, Standardauswahl und Bilder

Öffnen Sie in der Attributzeile „Attributwerte anlegen“. Jede Zeile entspricht einer auswählbaren Ausprägung. Geben Sie eine kundenverständliche Bezeichnung, die Multiplikatormenge und gegebenenfalls einen Nettopreis ein. Das Keyword ist eine zusätzliche Kennung. Die Spalte „wenn Regel“ gehört zu bedingten Werten; verwenden Sie dort nur eine für Ihren Ablauf eingerichtete Regel.

Markieren Sie den vorgesehenen Standardwert und ergänzen Sie bei Bedarf ein Bild. Beispiel: „Ohne Geschenkverpackung“ kann der Standard mit 0 Euro sein, „Geschenkpapier Salbei“ ein zusätzlicher Wert mit 3 Euro netto. Speichern Sie die Werte. Kontrollieren Sie anschließend die übergeordnete Set-Konfiguration und die Artikelzuordnung.

Berechnung und Shopausgabe prüfen

Verwenden Sie die Attributset-Vorschau, um Kombinationen und Rechenwege zu prüfen. Die Vorschau dient besonders der Berechnung; die tatsächliche optische Ausgabe prüfen Sie zusätzlich am Produkt im Shop. Wählen Sie jede Option, vergleichen Sie Zwischen- und Endpreis und testen Sie die Pflichtauswahl.

Prüfen Sie bei ausgeblendeten Attributen den Standardwert, bei Multiplikatoren die Reihenfolge und bei reinen Hilfswerten den Schalter „Addieren“. Eine Preisabweichung lässt sich so gezielt auf eine Zeile eingrenzen. Auf schmalen Bildschirmen sind die Tabellen horizontal scrollbar; beachten Sie die rechts liegenden Spalten „Anzeige“ und „Werte“.

Die Abbildungen zeigen fiktive Produkte, Personen und Bestellungen eines separaten Demoshops. Sichtbare Bereiche richten sich nach Benutzerrechten und Shopkonfiguration.
