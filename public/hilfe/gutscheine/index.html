Gutscheinset vorbereiten

Ein Gutscheinset fasst Wert, Bedingungen und die daraus erzeugten Codes zusammen. Legen Sie ein neues Set an oder wählen Sie ein vorhandenes. Vergeben Sie eine interne Bezeichnung, legen Sie Aktivität bzw. Gültigkeitszeitraum fest und tragen Sie bei Bedarf einen Mindesteinkaufswert ein.

Der Gutscheinwert ist entweder absolut oder prozentual. Kontrollieren Sie die gewählte Art zusammen mit dem Betrag. Ein 10-Euro-Gutschein und ein 10-Prozent-Gutschein sind unterschiedliche Aktionen. Speichern Sie die Definition, bevor Sie Codes erzeugen.

Artikel und Kunden begrenzen

Unter „Auf Artikel“ wählen Sie alle Artikel, eine Auswahl oder eine Ausschlussauswahl. Übernehmen Sie die vorgesehenen Produkte bzw. Kategorien mit den angebotenen Zuordnungsfunktionen. Unter „Auf Kunden“ gilt das Set entweder allgemein, für bestimmte Kunden oder für eine Kundengruppe.

Prüfen Sie gemeinsam Zeitraum, Mindestwert, Artikel und Kundenzuordnung. Ein korrekt eingegebener Code kann im konkreten Warenkorb trotzdem nicht anwendbar sein. Testen Sie deshalb einen passenden und einen bewusst unpassenden Fall.

Codes erzeugen, anzeigen und exportieren

Bei „System generiert“ legen Sie die benötigte Anzahl fest und erzeugen individuelle Codes. Bei „eigene Eingabe“ geben Sie einen gemeinsamen Aktionscode ein. Die alte Hilfe unterscheidet einmalige Systemcodes und wiederverwendbare eigene Codes; kontrollieren Sie das gewünschte Einlöseverhalten im konkreten Shop, bevor Sie eine Aktion veröffentlichen.

Nach der Erzeugung sind Teile der Set-Definition nicht mehr frei bearbeitbar. Das erklärt auch ausgegraute Felder bei einem bereits erzeugten Set. Für andere Bedingungen erstellen Sie ein neues Set, statt einen bereits verteilten Code stillschweigend umzudeuten.

Über „Gutscheine anzeigen“ sehen Sie die erzeugten Codes. Der Export dient der Weiterverarbeitung. Behandeln Sie tatsächlich gültige Codes wie einlösbare Werte und veröffentlichen Sie keine vollständige Codeliste versehentlich in einer Hilfeaufnahme.

Einlösung und Löschen kontrollieren

Prüfen Sie den Abzug, den verbleibenden Warenkorbwert, Gültigkeit und Kundenbindung. Kontrollieren Sie auch das Zusammenspiel mit automatischen Rabatten. Aus einer separat funktionierenden Gutscheinregel folgt nicht, dass jede Kombination gewünscht ist.

Beim Löschen eines Sets können die zugehörigen Codes betroffen sein. Prüfen Sie daher vorab bereits verteilte oder verwendete Codes. Die neutrale Demo verwendet ausschließlich fiktive Beispiele.

Die Abbildungen zeigen fiktive Produkte, Personen und Bestellungen eines separaten Demoshops. Sichtbare Bereiche richten sich nach Benutzerrechten und Shopkonfiguration.
