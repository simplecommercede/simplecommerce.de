HTML-Editor und WYSIWYG

Ein HTML-Editor hilft, Inhalte für Webseiten zu formatieren. In der visuellen Ansicht sehen Sie Absätze, Überschriften und Listen während der Bearbeitung. WYSIWYG bedeutet sinngemäß „Was Sie sehen, entspricht der Ausgabe“. Die endgültige Darstellung prüfen Sie trotzdem im verwendeten Shoptemplate.

Die aktuelle Werkzeugleiste bietet Absatzformat, Rückgängig/Wiederholen, Fett, Kursiv, Unterstreichen, Listen, Einzüge, Links, Bilder und Tabellen. „Tx“ entfernt Formatierungen; „HTML“ öffnet die Quelltextansicht. Die Tabellenauswahl enthält Aktionen für Zeilen, Spalten und Tabelleneigenschaften. Verwenden Sie Tabellen für zusammengehörige Daten und prüfen Sie schmale Ansichten.

HTML, XHTML und Sonderzeichen

HTML beschreibt die Struktur einer Webseite. Beispielsweise kennzeichnet <p>Text</p> einen Absatz. Ändern Sie bei normaler Textpflege den Inhalt und erhalten Sie passende öffnende und schließende Markierungen. XHTML bezeichnet eine strengere, XML-basierte Schreibweise von HTML und begegnet Ihnen vor allem in älteren Vorlagen.

Schreiben Sie Umlaute und Sonderzeichen normalerweise direkt im Editor. In HTML-Quelltext müssen Zeichen mit besonderer Bedeutung passend geschrieben werden, beispielsweise &amp; für ein kaufmännisches Und oder &lt; für ein sichtbares Kleinerzeichen. Kontrollieren Sie nach dem Speichern, ob das Zeichen tatsächlich angezeigt wird.

Variablen und Platzhalter

Eine Variable steht für einen Wert, der bei der Ausgabe eingesetzt wird, etwa Kundenname oder Bestellnummer. Wählen Sie Platzhalter aus der aktuellen Variablenliste und übernehmen Sie sie vollständig. Platzhalter sind nicht automatisch normaler Text, den Sie beliebig umbenennen oder übersetzen können.

Prüfen Sie die Ausgabe mit einem konkreten Beispiel. Ein Platzhalter für Bestelldaten benötigt einen passenden Bestellkontext. Bedingungen steuern, wann ein Textblock erscheint; erhalten Sie deren vollständige Struktur.

API, XML und RSS

Eine API ist eine definierte Schnittstelle, über die Programme Daten oder Funktionen austauschen. Welche Angaben erforderlich sind und wie ein Vorgang bestätigt wird, legt die jeweilige Schnittstelle fest.

XML ist ein strukturiertes Textformat für Daten. Eine XML-Datei ist nicht automatisch eine sichtbare Shopseite. RSS verwendet strukturierte Feeds, um etwa neue Produkte oder Nachrichten bereitzustellen. Titel, Beschreibungen und Links pflegen Sie in der RSS-Verwaltung.

W3C und Vorlagenpflege

Das W3C entwickelt Webstandards. Für Ihre tägliche Pflege sind eine klare Inhaltsstruktur, vollständige Markierungen, aussagekräftige Links und verständliche Bildbeschreibungen wichtig. Bewahren Sie eine funktionierende Vorlage auf, bevor Sie umfangreich im Quelltext arbeiten.

Die Begriffe aus dem bisherigen Lexikon bleiben damit erklärt; die gezeigte Bedienung bezieht sich auf den aktuellen Editor.

Die Abbildungen zeigen fiktive Produkte, Personen und Bestellungen eines separaten Demoshops. Sichtbare Bereiche richten sich nach Benutzerrechten und Shopkonfiguration.
